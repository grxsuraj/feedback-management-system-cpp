# Feedback Management System (C++ OOP Project)

A console-based Feedback Management System developed using C++ and Object-Oriented Programming (OOP) concepts.

## Features

* Submit student feedback
* View all feedback records
* Delete all feedback records
* File handling using `feedback.txt`
* Menu-driven console application

## OOP Concepts Used

* Classes and Objects
* Encapsulation
* Constructors

## Technologies Used

* C++
* OOP
* File Handling

## Project Structure

```text
feedback-management-system-cpp/
│
├── main.cpp
├── feedback.txt
└── README.md
```

## How to Run

### Compile

```bash
g++ main.cpp -o feedback
```

### Run

#### Windows

```bash
.\feedback.exe
```

#### Linux / Mac

```bash
./feedback
```

## Sample Menu

```text
1. Submit Feedback
2. View Feedback
3. Delete All Feedback
4. Exit
```
